# carmarket-collector

Сборщик машин для сайта [машиныпонизурынка.рф](https://машиныпонизурынка.рф).

Читает открытые Telegram-каналы через `t.me/s/<канал>`, разбирает посты правилами, сжимает фото в WebP и отправляет готовые файлы на сайт по HTTPS. Данные (машины, фото, состояние) хранятся на сервере сайта, в этом репозитории только код.

Запускается GitHub Actions (`.github/workflows/collect.yml`) по команде с сервера сайта, примерно раз в 3 минуты днём и раз в 15 минут ночью.

Основной проект и тесты лежат в закрытом репозитории, этот код копируется оттуда.

| Файл | Что делает |
|---|---|
| `collector/collect.py` | Запуск: читает каналы, собирает `cars.js` и фото |
| `collector/telegram.py` | Читает страницы канала |
| `collector/lex_auto.py` | Правила канала Lex Auto |
| `collector/nizherinka.py` | Канал-доска "Ниже рынка СПБ": телефоны и имена продавцов не сохраняются, карточка ведёт на пост |
| `tools/build_data.py` | Общие правила разбора текста |
| `tools/push.py` | Отправка файлов на сайт (токен только в секретах GitHub) |
